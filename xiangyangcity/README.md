# 南宋襄樊 · 汉江古战图 (1267–1273)

南宋末年襄阳古城与浩瀚汉江江防的三维交互式历史舆图。

- 拖动旋转、滚轮缩放、右键平移自由漫游
- 点击城防要塞或战场遗迹，自动平滑飞近巡视
- 详尽配有历史典故、战事沿革与宋词赋文解说
- 采用水墨宣纸阶梯光照 Shader 与波光粼粼的青碧流动汉江水效
- 支持多图层切换：【城池堡垒】、【江防战船】、【攻城炮阵】
- 适配桌面端与移动端浏览器触控

## 文件

- `index.html`：主页入口（南宋襄阳城与汉江三维古战图）
- `xiangyang.html`：同源镜像单文件
- `xiangyang_geo_processed.json`：依据 OpenStreetMap 提取的真实襄阳古城墙与护城河几何数据
- `.nojekyll`：让 GitHub Pages 直接发布网页文件

本项目为独立静态网页，无需安装依赖或构建，直接双击或通过静态服务器打开即可。

## 地图与数据来源

- 襄阳古城墙、濠水（大护城河）与汉江水系矢量数据来自 OpenStreetMap，遵循 ODbL 1.0 许可协议。
- 历史要塞尺度与战争记载考证依据《宋史·吕文德传》《宋史·张顺张贵传》及南宋舆地文献。
- 3D 渲染引擎基于 Three.js (MIT License)。
