# 宋式补间铺作斗拱 3D 互动模型 (静态发布版)

本项目是依据北宋李诫《营造法式》及梁思成《营造法式注释》（图样十一“五铺作重栱出单杪单下昂，裏转五铺作重栱出两杪，并计心”）构建的**高精度榫卯咬合与零间隙拼合 3D 互动模型**。

## 🚀 静态部署与发布方式

由于本目录内所有 3D 库（Three.js 与 OrbitControls）均通过标准 ES Module CDN 加载，且所有图纸资源均采用同级相对路径，您可以直接使用以下任一方式发布上线：

### 方式一：GitHub Pages 发布（推荐，永久免费托管）
1. 将 `dougong_publish` 目录内的所有文件推送到 GitHub 仓库的 `main` 分支（或新建一个专门的 `gh-pages` 分支）；
2. 进入仓库的 **Settings -> Pages**；
3. **Build and deployment** 的 Source 选择 **Deploy from a branch**，Branch 选择 `main`（或 `gh-pages`）根目录 `/ (root)`；
4. 保存后等待约 1 分钟，即可获得类似 `https://<用户名>.github.io/<仓库名>/` 的公开访问网址！

### 方式二：Vercel / Netlify / Cloudflare Pages（零配置一键上线）
* **Vercel**：在本地或通过网页导入项目，将 Root Directory 设置为 `dougong_publish`，Framework Preset 选择 `Other`，直接点击 **Deploy** 即可秒级发布。
* **Netlify**：直接将 `dougong_publish` 文件夹拖拽进 Netlify 的 **Drag and drop your site folder here** 区域，立即生成专属全球 CDN 链接。

### 方式三：Nginx / Apache / 传统虚拟主机
将 `dougong_publish` 目录下的全部文件上传至 Web 根目录（如 `/var/www/html` 或 `public_html`）即可。

### 方式四：本地临时预览
如果要在本地电脑上直接预览运行（避免浏览器的 `file://` 跨域拦截）：
```bash
# 进入发布目录
cd dougong_publish

# 使用 Python 启动本地临时静态服务器
python3 -m http.server 8080

# 访问浏览器：
# http://127.0.0.1:8080
```
或者使用 Node.js：
```bash
npx serve dougong_publish
```

## 🎯 核心特色与功能

1. **宋代材栔制严格对齐**：
   * 严格遵循 1 材 = 15 分 = 1.20、1 栔 = 6 分 = 0.48（自然空隙）、1 材厚 = 10 分 = 0.80。
   * 栌斗、交互斗（十八斗）、齐心斗、散斗（槽升子）槽底与各层栱枋严丝合缝（零空隙）。
2. **构件齐全与立面图 3 号构件闭合**：
   * **立面图 3 号构件（里转第二跳华栱）**：自柱位 2 悬挑 30 分至柱位 1，五瓣卷杀挑头稳托柱位 1 十八斗底面，彻底杜绝悬空。
   * **10 号构件（裏耍头）**：大幅向室内挑出至 Z = -6.40，纯正宋式批竹造。
   * **11 号构件（下昂）**：刚直挺拔平直斜梁杠杆（斜率 1:2），宋式琴面昂嘴出跳 23 分。
   * **6 号构件（华头子）**：平正坐于正心慢栱与齐心斗之上，斜托下昂腹底。
3. **交互与演示**：
   * 支持 **一键顺次拆解 / 组装** 与 **自动往复动画**；
   * 支持 **老楠木材质**、**构件分色模式**、**X-Ray 透视模式**；
   * 顶部支持切换多种原版图纸半透明叠加比对（可调节透明度与显示隐藏）；
   * 点击任意构件可在右侧弹出宋代专业规制、柱位与受力卯榫说明卡片。
